# Gestão de tarefas

Cada arquivo Markdown representa uma unidade de trabalho rastreável.

## Convenção
`NNN-descricao-curta.md`

Exemplo: `001-criar-endpoint-pedidos.md`

## Fluxo de diretórios
- backlog: aguardando triagem
- in-progress: em execução
- review: aguardando decisão final
- done: concluída e aprovada
- failed: bloqueada/cancelada
